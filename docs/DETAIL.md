# 会话清理 Session cleanup

把历史会话「停用」：看报告 → 改名 → 归档，并把这场对话产生的文件收进 `手动删除/<会话标题>/`。

## 使用流程

输入框右下角常驻悬浮按钮「⌫ 会话清理」。

1. 点任意会话 → 弹出**报告**
2. 阅读报告（时间、消息、工具、目的、产物）
3. 需要回忆时点「全文回顾」，按时间线看自己说过的每句话
4. 在输入框输入 **`我确认停用`** —— 输入不匹配则确认按钮不可用
5. 执行：改名 + 归档；宿主随后自动把产物移入 `手动删除/<会话标题>/`

## 报告内容

| 字段 | 来源 |
| --- | --- |
| 开始 / 最后活动 | 会话事件的时间范围 |
| 消息 | 只计 `source.kind === 'user'` 的真人消息，排除 runtime-context / skill-catalog / time-context 注入 |
| 工具 | `tool/call` 事件统计 |
| 目的 | 第一条真人消息原文 |
| 产物 | 日志中引用过、且落在会话工作区内的文件，附**写入次数**与首次写入时间 |

## 边界与安全

- 边界取**该会话日志里记录的工作区**（`header.cwd`），不使用全局默认值
- 移动前 `realpathSync` 解析真实路径，防符号链接逃逸
- `..` 路径穿越解析后判定并拒绝
- 无工作区记录的会话 → 拒绝移动，只允许归档
- 不删除任何数据

## 文件夹规则

- 一个会话一个文件夹，名字 = 会话最终标题（`已停用 YYYYMMDD` / `已停用 YYYYMMDD-2`）
- 标题重名时自动加序号
- 归档后自动收集；历史上遗漏的可用 `sweep` 补收并重新归位
- 外部导入、无归属的文件用 `move` 收进任意子文件夹（如 `未归属上传`）

## 已知限制

- 不能恢复：归档是终态
- 共享文件：谁先停用归谁
- 只识别日志里出现过的路径；脚本内部生成或外部工具写入的文件找不到
- 客户端分页上限 8000 事件，超大会话统计会被截断并在报告标注
- 面板内无法调用 AI（`remote.llm` 只提供配置类方法），摘要请用「复制全文」交给外部处理

## 工具

`session_cleanup`：`list` / `scan` / `collect` / `move`（支持文件夹）/ `sweep`（`dry` 预览）。

运行日志：`~/.dsh/session-cleanup.log`（英文），跳过原因代码 `outside-workspace`、`realpath-outside-workspace`、`already-in-trash`、`missing`、`not-a-file`。
